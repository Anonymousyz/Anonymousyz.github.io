# Project status

## Project type

A static portfolio site for publicly reviewable work, methods, and project summaries.

## Current public state

Maintained. The published site is built from the `main` branch through GitHub Pages; build and link checks run locally and in repository CI.

## Intended use

Use the site to navigate public work and understand what each item covers, its limits, and its evidence.

## Not a claim of

It is not a customer deployment, consulting offer, or claim that any example has completed production acceptance.

## Feedback and maintenance

Report broken links, factual errors, or accessibility issues through GitHub Issue. The repository's checks are listed in `package.json`.

## Public boundary

Only public, fictional, or de-identified material belongs here. Do not submit confidential project information through issues or pull requests.
