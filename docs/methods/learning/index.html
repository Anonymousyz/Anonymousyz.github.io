持续学习好奇心 · 问题 · 检验 · 调整

遇到拿不准的判断，或第一次接触的系统，我会去查它的依据和运行方式。学什么，取决于手头要解决什么问题。学完后，要能把它讲清、写清，或用在实际任务里。

学什么，先看手头的问题

遇到一项判断，我会查它凭什么成立；面对一个陌生系统，也会先弄清它怎样运行。问题越多，越要分轻重缓急，先解决正在做的事。

动手前，我会记下这次要解释的现象、要作的判断或要完成的事。目标具体，才知道该找什么材料，也看得出自己到底学会没有。

把新概念放回已有知识里

我常从综述或入门材料开始，弄清基本概念和主要争议，再回到标准、论文、政策文件或产品文档核对关键定义。不同来源说法不一，就查时间、对象、定义、统计口径和适用条件。

学到新概念，要把它放回正在处理的问题里：它和哪些旧概念有关，能解释什么，在哪些条件下会失效。只记住术语，换个问题往往还是不会用。

学习方法按需要来用

合上材料，试着把关键内容说出来，学习研究把这种做法叫“提取练习”。如果只能重复术语，却不能用自己的话解释，说明还没有真正弄懂。需要长期记住的内容，就隔一段时间再复习。

用过多少方法、读过多少材料，都不是结果。最后要看能不能写清、讲明，或把事情做出来。

写清、讲明，才算学会

我会把所学内容写成说明，画出概念之间的关系，讲给别人听，或做成一条能运行的规则。写不清、讲不明、做不出来，往往是定义还含混、推理有跳步，或材料还不够。

概念说不清、公式写不全、材料撑不起结论，或程序和规则对不上，我就回到来源重查。有没有学会，要看眼前的工作能不能完成，不能只数读过多少材料。

换个问题，看能不能用

换一组材料，仍能按同一口径判断，属于近迁移；换到另一个领域，还能认出相同结构，属于远迁移。后一种情况尤其要重新核对机制和条件，不能拿类比当证据。

实际使用出了问题，我会先分清是知识有缺口、当时没想起来、场景判断错了，还是方法本身不合适，再决定补材料、换练习或重新梳理概念。

根据结果换一种学法

熟悉一段话不等于掌握。我会记下原来怎么理解、在哪里卡住、哪次写作或应用暴露了问题，以及后来为什么改。心理学把这类自我检查称为“元认知监测”。

如果写作或实际应用没有改善，我就换一种学法：合上材料回忆，找反例，请别人听我解释，或把任务拆小后再练。

说明

适用边界

  • 好奇心容易让人分心。任务有明确期限时，我先学完成当前工作所必需的内容。
  • 较快了解一个领域，不等于取得了专业资格。涉及专业结论，仍要请相应人员复核。
  • 测评和学习方法只能说明偏好与过程。能否做好工作，要看作品、项目结果和长期表现。
